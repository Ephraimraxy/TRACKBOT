# Project report

`TrackBot_Project_Report_Chapters_1-5.docx` is the Word report (Chapters One to Five, references and Appendices A to G). The `.pdf` next to it is a rendering of the same file, made with LibreOffice, so page breaks can differ slightly from Word. After opening the Word file, press Ctrl+A and F9 to refresh page numbers in the lists of contents.

- `figures/` the diagrams drawn for the report (conceptual framework, order lifecycle, ER diagram, chatbot flow, architecture, payment sequence).
- `screenshots/` the screens shown in Section 4.4, captured from the demonstration data (`npm run seed:demo`).

The test numbers in the report come from `npm test` (361 tests, 26 files) and `tests/live/*.mjs` (65 checks).
